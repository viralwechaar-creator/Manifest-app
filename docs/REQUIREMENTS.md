# Confirmed requirements (from the school)

## Design
- Big fullscreen hero image on the front page (kept).
- Light, fresh, warm colour palette that feels calm, trustworthy and premium.
- Curved/rounded shapes on the footer, cards and other small elements (not on the hero).
- Mobile sign-in: full-screen image with a "Sign in" button that opens the form as a bottom sheet.

## Students and parents
- The student ID is assigned automatically **during admission** (when the application is approved/confirmed).
- Parents receive a username (the student ID) and a password for the portal when admission is confirmed.
- Student ranking in class tests and exams.

## Staff
- Teacher and staff attendance managed in the system.
- Lecture/period schedule (timetable) for teachers managed in the system.
- Vacant periods and substitution: when a teacher is absent or on leave, their periods become vacant and a free teacher can be assigned as substitute (with notification).

## Phase placement
Phase 3: student/teacher records, classes, subjects, ID generation rules. Phase 4: timetables, staff-aware vacancy and substitution, attendance, tests, rankings. Phase 5: parent login. Phase 6: admission workflow that issues the ID and parent credentials.
